# Masters Features Sandbox / Staging Directory

This directory contains isolated components and features created by Masters from remote `origin/main`.
These components are staged here so they can be integrated piece-by-piece into the restored tactical dashboards without overwriting existing local dashboard UIs or navigation.

## Included Components
- `AgencyIncidentQueue.tsx`: Priority queue component for agency dispatchers.
- `MapLeaflet.tsx`: Leaflet CartoDB Dark & Esri Satellite tactical map.
